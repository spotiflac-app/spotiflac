# SpotiFLAC branding

Vector artwork is in `logo/svg/`; PNG exports are in `logo/png/`.
The wordmarks use SpotiFLAC with the existing download symbol and palette.

- Deep Teal: `#1E4E4F`.
- Mist: `#BBEBEC`.
- Ink: `#121616`.
- Paper: `#FFFFFF`.

Launcher icons use the symbol without lettering. Regenerate platform icons
with `dart run flutter_launcher_icons` after changing the source icon files.
